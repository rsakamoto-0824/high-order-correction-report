3. run_all の処理フロー

3.1 全体フロー

  1. 開始条件を読み、準備する cfg = simulation_config()。引数があれば1以上か確認し、cfg.shotCount を上書き（1未満ならエラー）。results/ と report/figures/ がなければ作る。rng(20260913, 'twister') で乱数を初期化し、経過時間の計測を始める。
  2. 手順1座標を作る（build_geometry） マーク35点と評価グリッド441点の座標 [mm] → geometry（3.2節）
  3. 手順2補正式とVIF削減版を作る（build_model_variants） ASML式・ニコン式の設計行列、VIF、削除する項 → variants（ASML、Nikon、Nikon-VIF）と vif_table.csv（3.3節）
  4. 手順3Shotを生成する（generate_shots） 真の歪み、偶然誤差、異常値を乱数で作る → data（3.4節）
  5. 手順4回帰手法の一覧を作る（build_methods） 損失関数3種類×罰則の条件5種類 = 15手法 → methods（3.5節）
  6. 手順5回帰と評価のループ シナリオ2×補正式3×軸2×手法15 = 180回の fit_batch。Shotごとの残差RMS → rmsTrue、rmsApparent、summary.csv（3.6節）
  7. 手順6dx・dyをまとめて要約する（summarize_combined） → summary_combined.csv（3.7節）
  8. 手順7参考値を求める（compute_reference） 補正なしの歪みと、各補正式の表現限界 → reference.csv（3.8節）
  9. 手順8条件どうしを比べる（compare_conditions） 低減率と勝率 → comparisons.csv（3.9節）
  10. 手順9λの感度解析（sweep_lambda） 異常値ありのデータで、Huber回帰＋罰則のλを変える。144回の fit_batch → lambda_sweep.csv（3.10節）
  11. 終了保存する 全変数を simulation_results.mat に保存し、「完了: … 秒。」と表示する（3.11節）

3.2 座標を作る（build_geometry）

座標はすべてShot中心を原点とするmm単位です。補正式の x, y にこの値をそのまま使います（正規化はしません）。

geometry の中身
変数大きさ作り方
markX, markY35×1meshgrid(markXmm, markYmm) を列ベクトルにしたもの。x の列ごとに y が7行並ぶ順番（列優先）
evalX, evalY441×1x を −13〜13 mm、y を −16.5〜16.5 mm でそれぞれ21等分した格子。Shot端を含むため、マークの外側（|x| > 12 mm、|y| > 15.5 mm）も評価する

3.3 補正式とVIF削減版を作る（build_model_variants）

ASML式とニコン式のそれぞれについて、dx の式と dy の式を順に処理します。

繰り返し: 補正式（ASML → Nikon）
繰り返し: 軸（x = dx の式 → y = dy の式）
  1. a項を読むmodel_terms から指数 exp（p×2）と係数名 name（例: k1, k3, …）を取り出す（4.1節）
  2. bマーク位置の設計行列を作るAraw = design_matrix(markX, markY, exp)（35×p、4.2節）
  3. c全項のVIFを計算するvifFull = compute_vif(Araw, exp)（4.3節）
  4. dVIFで項を削除する[keepMask, removalLog] = reduce_terms_by_vif(Araw, exp, 10)（4.4節）。残した項だけでVIFを計算し直して vifAfter とする
  5. eVIFの表の行を作る項ごとに Model, Axis, Term, Monomial, Order, VIF, Kept, RemovalOrder, VIFAfter
  6. f回帰用の設計を作る（make_design）全項版と、残した項だけの削減版の2つ
  1. 判定dx・dy のどちらかで削除した項があるか
    ある元の式（例: Nikon）と削減版（Nikon-VIF）の両方を variants に加える
    ない削減版は元の式と同じなので、元の式（例: ASML）だけを加える

現在の条件（マーク5×7点）では、次の3種類になります。

make_design（列の標準化）

罰則の効き方を項の間でそろえるため、切片以外の列を、マーク35点での平均0・標準偏差1に変換します。評価グリッドの列にも、マーク位置で求めた同じ平均と標準偏差を使います。

centerj = meani(Arawij)，scalej = stdi(Arawij)（n で割る標準偏差）
Astdij = (Arawij − centerj) / scalej，Aevalkj = (Xevalkj − centerj) / scalej 切片の列（指数 [0 0]）だけは center = 0、scale = 1（すべて1のまま）
設計（variants(v).x / variants(v).y）の中身
変数大きさ内容
exponentsp×2項の指数 [m n]（xmyn）
names1×p係数番号（k1, k3, …）

注意

回帰で求まる係数 θ は標準化した列に対する値で、kパラメータそのものではありません。kパラメータに直すには、切片以外は kj = θj / scalej、切片は k = θ切片 − Σj θj·centerj / scalej とします。現在のスクリプトはkパラメータを出力していません（評価には補正値だけを使うため）。

3.4 Shotを生成する（generate_shots）

真の歪みの項は、ASML式とニコン式の項の和集合です（model_terms('Truth')）。ASML式の項はすべてニコン式に含まれるので、結果としてニコン式と同じ項（dx 12項、dy 15項）になります。

乱数は次の順番で使います。この順番が変わると、同じシードでも別のShotになります。

  1. 1異常値にするマークを決める isOutlierMark = rand(35, S) < 0.05。dx と dy で共通（同じマークの両方の測定値が異常値になる）
  2. 繰り返し: 軸（x → y）
    1. 2項がそのShotに現れるかを決める isActive = rand(T, S) < 出現確率(次数)
    2. 3係数を作る coefficient = randn(T, S) × σ(次数) × isActive ÷ (13m × 16.5n)。σ はShot端での変位量なので、Shot端の座標のべき乗で割ってmm単位の係数 [nm/mm次数] にする
    3. 4真の歪みを計算する マーク位置 trueAtMarks（35×S）と評価グリッド trueAtEval（441×S）。どちらも「設計行列×係数」（標準化はしない）
    4. 5偶然誤差を作る noise = 0.3 × randn(35, S)
    5. 6異常値の大きさと符号を作る 大きさ 3 + 5 × rand(35, S)、符号 2 × (rand(35, S) < 0.5) − 1。異常マーク以外では0にする
    6. 7測定値を作る 異常値なし measuredClean = trueAtMarks + noise
      異常値あり measuredOutlier = trueAtMarks + noise + outlier
      2つは同じ偶然誤差を共有するので、異常値の有無だけを比べられる
真の歪みの項（係数を作る順番）

3.5 回帰手法の一覧を作る（build_methods）

損失関数ごとに「罰則なし、L2・L1を高次項のみ、L2・L1を全項」の5種類を作ります。手法は構造体（name, loss, penalty, scope）で表します。

15種類の手法（この順番で計算し、表にも並べる）
番号手法名 name損失 loss罰則 penalty罰則の対象 scope
1OLSOLSnonenone
2OLS+L2(HO)OLSL2HO（高次項のみ）
3OLS+L1(HO)OLSL1HO
4OLS+L2(All)OLSL2All（全項）
5OLS+L1(All)OLSL1All
6〜10LAD, LAD+L2(HO), LAD+L1(HO), LAD+L2(All), LAD+L1(All)LAD1〜5と同じ並び
11〜15Huber, Huber+L2(HO), Huber+L1(HO), Huber+L2(All), Huber+L1(All)Huber1〜5と同じ並び

penalty_mask(design, scope) は、罰則をかける項を表す論理ベクトル（p×1）を返します。All ならすべて true、HO なら design.isHighOrder（2次以上の項だけ true）、罰則なしならすべて false です。

3.6 回帰と評価のループ

繰り返し: シナリオ（outlier: 異常値あり → clean: 異常値なし）
繰り返し: 補正式（ASML → Nikon → Nikon-VIF）
繰り返し: 軸（x → y）。測定値 measured は、シナリオに応じて measuredOutlier か measuredClean（35×S）
繰り返し: 手法（15種類）
  1. 1罰則をかける項を決めるisPenalized = penalty_mask(design, method.scope)
  2. 2回帰する（1000 Shotをまとめて）theta = fit_batch(design.Astd, measured, method, isPenalized, λ1, λ2, cfg) → p×S（5章）
  3. 3Shot全面の補正残差を計算するtrueResidual = trueAtEval − Aeval × theta（441×S）→ rmsTrue{sc, v, m, a} = 列ごとの二乗平均平方根（1×S）
  4. 4測定点での見かけの残差を計算するmeasured − Astd × theta（35×S）→ rmsApparent{sc, v, m, a}（1×S）
  5. 5要約の行を作り、進み具合を表示する中央値、95パーセンタイル、|平均|+3σ、見かけの残差の中央値（6章）。例: [ 82.0s] outlier Nikon OLS+L1(HO) dy median RMS = 0.493 nm

ループが終わると、行をまとめて summary.csv に書き出します。fit_batch の呼び出しは 2×3×2×15 = 180回で、1回ごとに1000 Shotを処理します。

3.7 dx・dyをまとめて要約する（summarize_combined）

レポートの表では、dx と dy の残差RMSをShotごとに1つの値にまとめて使います。

RMSまとめ(Shot s) = √( ( RMSdx(s)2 + RMSdy(s)2 ) / 2 ) 局所関数 combined_rms。見かけの残差にも同じ式を使う

シナリオ×補正式×手法ごとに、まとめた値の中央値、95パーセンタイル、見かけの残差の中央値を summary_combined.csv（90行）に書き出します。

3.8 参考値を求める（compute_reference）

  • 補正なし: 評価グリッドの真の歪みそのもののRMS（rawRms）。
  • 表現限界: 雑音のない真の歪みを、評価グリッドの441点すべてで最小二乗法により当てはめたときの残差RMS（floorRms）。Aeval \ trueAtEval で解きます。その補正式の項では表せない歪みの大きさを表します。

軸ごと・条件ごとの中央値と95パーセンタイルを reference.csv（dx・dy それぞれ4行、計8行）に書き出します。

3.9 条件どうしを比べる（compare_conditions / comparison_pairs）

4. 補正式とVIF

4.1 補正式の定義（model_terms.m）

補正式は、露光機メーカーごとに定められたShot高次補正演算式です。項・係数番号・変数・符号を変えずに、指数 [m n] と係数番号の組として書いています。x, y はShot中心を原点とするマーク座標 [mm]、dx, dy は [nm] です。

ASML式
dx = k1 + k3·x + k5·y + k7·x2 + k11·y2 + k13·x3 + k19·y3
dy = k2 + k4·y + k6·x + k8·y2 + k10·xy + k12·x2 + k14·y3 + k16·xy2
ニコン式
dx = k1 + k3·x + k5·y + k7·x2 + k9·xy + k11·y2 + k13·x3 + k17·xy2 + k19·y3 + k29·y4 + k41·y5 + k55·y6
dy = k2 + k4·y + k6·x + k8·y2 + k10·xy + k12·x2 + k14·y3 + k16·xy2 + k18·x2y + k22·y4 + k24·xy3 + k32·y5 + k34·xy4 + k44·y6 + k46·xy5
model_terms の呼び方
引数返す内容
'ASML', 'Nikon'model.x.exp / model.y.exp（指数）と model.x.name / model.y.name（係数番号）。k1〜k6 が線形成分（並進・倍率・回転）
'Truth'ASML式とニコン式の指数の和集合（重複を除き、ASML式の順番を先にする）。名前は monomial_label で作る表示名
それ以外エラー「未対応のモデル名です」

最後に、項の数と係数名の数が一致しているか確認し、違えばエラーにします。

4.2 設計行列（design_matrix.m）

Aij = ximj · yinj 行 i が点（マークまたは評価点）、列 j が項。x と y の点数が違うとエラー

monomial_label.m は指数 [m n] から表示名（例: [2 1] → x^{2}y、[0 0] → 1）を作ります。表と図のラベルに使います。

4.3 VIFの計算（compute_vif.m）

  1. 1列の大きさをそろえる各列を、その列の絶対値の最大値で割る。mm座標のべき乗は列ごとに桁が大きく違う（例: y6 は約107）ため。VIFは列を定数倍しても変わらない
  2. 繰り返し: 切片以外の項 j
    1. 2項 j の列を、他のすべての列（切片を含む）で回帰するバックスラッシュ演算子で最小二乗解を求め、当てはめ値を計算する
    2. 3VIFを求めるR2 = 1 − 残差平方和 / 全平方和（平均からの偏差）、VIF = 1 / max(1 − R2, eps)

切片のVIFは対象外なので NaN を返します。VIFはマーク配置と項の組だけで決まり、測定値には依存しません。

4.4 VIFによる項の削除（reduce_terms_by_vif.m）

切片と1次項（並進・倍率・回転）は削除しません（保護する項）。

  1. 開始すべての項を残す状態から始める
  2. 1残している項だけでVIFを計算する
  3. 判定すべてのVIFがしきい値（10）未満か
    はい終了する
    いいえ次へ進む
  4. 判定保護する項以外に、VIFがしきい値以上の項があるか
    あるその中で次数が最も高い項に絞り、さらにVIFが最大の項を選ぶ（y3 を消して y6 を残すような、多項式の階層に反する削除を避けるため）
    ないしきい値以上は1次項だけ。保護する項以外の中でVIFが最大の項（1次項と相関している高次項）を選ぶ
  5. 判定選んだ項のVIFが有限か
    はいその項を削除し、番号と削除直前のVIFを記録して手順1に戻る
    いいえ削除できる高次項が残っていないので終了する
  6. 出力keepMask と removalLogkeepMask: 残す項なら true。removalLog: [削除した項の番号, 削除直前のVIF] を削除した順に並べたもの

5. 回帰計算（fit_batch.m）

5.1 入力と出力

fit_batch(A, Y, method, isPenalized, lambdaL1, lambdaL2, cfg)
引数・戻り値大きさ内容
A35×p標準化した設計行列（切片列を含む）
Y35×S測定値 [nm]。1列が1 Shot
method構造体loss（OLS / LAD / Huber）と penalty（none / L2 / L1）を使う
isPenalizedp×1罰則をかける項なら true

入力チェック: 損失や罰則の名前が対応外、A と Y のマーク数が違う、isPenalized の長さが項数と違う場合はエラーにします。

5.2 目的関数

Shotごとに次の目的関数を最小にします。ri はマーク i の残差、s はそのShotの残差の尺度、n = 35 です。

損失　OLS: (1/2n) Σi ri2　　LAD: (1/n) Σi s·|ri|　　Huber: (1/n) Σi s2·ρc(ri / s)
罰則　L2: (λ2/2) Σj∈罰則項 θj2　　L1: λ1 Σj∈罰則項 |θj| ρc(u) = u²/2（|u| ≤ c）、c|u| − c²/2（|u| > c）。LADとHuberは、重み付きの (1/2n) Σ wi ri2 を重みを更新しながら解き直して最小化する（IRLS）

5.3 全体フロー

  1. 開始入力をチェックする
  2. 1初期解を求める全マークの重みを1にして solve_weighted を解く。OLSならこれが答え（OLS、OLS+L2、OLS+L1 の解）
  3. 判定損失はOLSか
    はい初期解を返して終了する
    いいえ（LAD・Huber）IRLSに進む
  4. 繰り返し: IRLS（最大1000回）。対象は、まだ収束していないShotだけ
    1. 2残差を計算するresidual = Y − A × theta（対象のShotの列だけ）
    2. 判定反復回数は20回以下か
      はい尺度を更新する: s = max(1.4826 × median|r − median(r)|, eps)
      いいえ尺度は前の値のまま（固定）
    3. 3重みを計算するrobust_weights（5.4節）
    4. 4重み付きで解き直すsolve_weighted。L1では、前の反復の係数を座標降下法の初期値にする（5.5節、5.6節）
    5. 5係数の変化を調べるShotごとに maxj|θ新 − θ旧| を計算し、係数を更新する
    6. 判定20回を過ぎていて、変化が 1e−5 nm 未満か
      はいそのShotは収束。以後の反復から外す。全Shotが収束したら終了
      いいえ次の反復も続ける
  5. 終了係数を返す1000回を過ぎても収束しないShotが残った場合は、個数と最大変化を警告に表示する（5.7節）

5.4 IRLSの重みと尺度（robust_weights）

マーク i の重み（Shotごとの尺度 s を使う）
損失重み wi考え方
LADs / max(|ri|, 0.1·s)残差の絶対値の和を最小にする重み。残差がほぼ0の点で重みが無限大にならないよう、|r| の下限を 0.1·s にする（残差が s 程度の点の重みは1程度）
Hubermin(1, 1.345·s / |ri|)残差が 1.345·s 以下の点は重み1（最小二乗と同じ）、それより大きい点は残差に反比例して重みを下げる
ポイント
  • 尺度を20回で固定する理由: 毎回更新すると、MADの値が隣り合う残差の間で行き来し、係数が振動して収束しないShotが出るためです。固定した後は凸な問題になり、反復は収束に向かいます。
  • LADに尺度 s を掛ける理由: 残差が s 程度の点の重みを最小二乗法と同程度にそろえ、罰則の効き方を損失関数の間でそろえるためです。罰則がなければ s は解に影響しません。
  • 収束したShotを外す理由: 収束の遅い一部のShotのために、全Shotの計算が続くのを避けるためです。結果は、外さない場合と許容誤差の範囲で同じです（50 Shotで中央値252行が一致することを確認済み）。

5.5 最小二乗とL2（solve_weighted / weighted_least_squares）

solve_weighted は罰則の種類で分岐します。

solve_weighted の分岐
罰則処理
noneweighted_least_squares（罰則行なし）
L2罰則行 √(n·λ2)·diag(isPenalized) を加えて weighted_least_squares
L1初期値が渡されていなければ、罰則なしの重み付き最小二乗解を初期値にして weighted_lasso

weighted_least_squares は、Shotごとに次の連立方程式を最小二乗の意味で解きます（MATLABのバックスラッシュ演算子、QR分解）。

[ √w ∘ A ; 罰則行 ] θ ≈ [ √w ∘ y ; 0 ] ∘ は行ごとの掛け算。罰則行を足すと、残差の二乗和に n·λ2·Σθj2 が加わり、(1/2n)Σw r2 + (λ2/2)Σθ2 の最小化と同じになる

5.6 L1（weighted_lasso: 座標降下法）

  1. 1Shotごとにグラム行列を作るG = ATWA / n（p×p）、b = ATWy / n。Gθ も計算しておく
  2. 繰り返し: 1周（最大20000周）。対象は、まだ収束していないShotだけ
    繰り返し: 項 j = 1 … p（全Shotをまとめて更新）
    1. 2項 j 以外で説明できない分を計算するρ = bj − (Gθ)j + Gjjθj
    2. 判定項 j は罰則をかける項か
      はいソフトしきい値処理: θj = sign(ρ)·max(|ρ| − λ1, 0) / Gjj
      いいえθj = ρ / Gjj
    3. 3Gθ を差分で更新し、変化量を記録するShotごとの変化量 = maxj |Δθj|·√Gjj
    1. 判定1周の変化量が 1e−7 未満のShotがあるか
      あるそのShotの係数を確定し、グラム行列などの配列から外す。全Shotが収束したら終了
      ない次の周へ
  3. 終了係数を返す20000周を過ぎても収束しないShotが残った場合は、個数と最大変化を警告に表示する

5.7 収束の判定と警告

fit_batch が出す警告
警告意味影響の見方
「IRLS（手法名）が 1000 回で収束しなかったShotが N 個あります（最大変化 …）。」LAD・Huberの反復が、N個のShotで上限に達した1000 Shotの本計算（2026-09-15）では、LAD・LAD+L1で1回あたり最大16 Shot（1.6%）、Huberで最大4 Shotに出た。中央値や95パーセンタイルへの影響は小さいと考えられるが、そのShotの係数はわずかに未収束のまま使われる
「座標降下法が 20000 回で収束しなかったShotが N 個あります（最大変化 …）。」L1の座標降下法が、N個のShotで上限に達した1000 Shotの本計算では、1回あたり1〜5 Shotに出た。表示される最大変化を判定値 1e−7 と比べて、実質的に収束しているかを判断する
